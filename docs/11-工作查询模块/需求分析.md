# 工作查询模块需求分析

## 1. 模块概述

工作查询模块用于查询和监控生产执行过程中的各类工作状态与检查记录，为生产管理人员提供实时的生产进度与质量信息，并为 APS 系统提供执行反馈数据。

## 2. 功能清单

- 生产工作开工检查实绩
- 生产工单开工检查实绩
- 交班记录
- 生产工单（查询视角）
- 生产工作
- 检验工作
- 工作(六状态查看)
- 派工工作查询

## 4. 业务规则

### 4.1 开工检查实绩

- 开工检查状态：已通过 / 未通过。  
- 检查通过后方可进行后续生产操作。  
- 检查不通过需关联异常联络单。  
- 检查记录不可删除，仅可新增。  

### 4.2 交班记录

- 交班记录按班次管理，记录交接双方信息。  
- 状态：待接收 → 已接收。  
- 支持关联附件（多条关联记录）。  
- 需记录计划数量与实际完成数量，便于对比分析。  
- 未达标分析字段用于记录差异原因。  

### 4.3 生产工单查询

- 本页面为查询视角，可查看工单完整状态。  
- 状态包含：创建 / 已下达 / 执行中 / 已完成 / 已完成不可维修 等。  
- 支持打印过程信息卡。  

### 4.4 生产工作

- 工作编号与工作名称为必填字段。  
- 时间单位默认为"分钟"，可配置其他单位。  
- 报告点、检验点、交接点为复选框，标识工作节点类型。  
- 实际处理时间 = 实际结束时间 - 实际开始时间。  

### 4.5 检验工作

- 检验数量统计：已检数量 = 合格数量 + 不合格数量。  
- 工作状态：创建 → 执行中 → 完成。  
- 检验类型关联工单类型（如：标准生产工单）。  
- 支持导出检验数据。  

### 4.6 工作(六状态查看)

- 六种状态：创建、下发、下达、执行中、完成、暂停。  
- 通过顶部 Tab 可快速过滤当前组织下各状态的工作。  
- 状态颜色标识：  
  - 蓝色（●创建）  
  - 黄色（●已下达）  
  - 绿色（●已完成）  
- 支持按工序、工作中心、班组等维度查询。  

### 4.7 派工工作查询

- 本页面为派工任务的查询视角，汇总展示所有派工任务状态。  
- 分派类型：人员 / 设备 / 班组。  
- 分派状态：未分派 → 已分派 → 已撤销。  
- 完成状态：未开始 → 执行中 → 已完成。  
- 支持按派工人、派工时间、分派状态等维度过滤查询。  
- 支持导出派工数据用于统计分析。  

### 4.8 与 APS 交互

- 开工检查实绩数据可反馈给 APS，影响排程决策。  
- 交班记录中的实际完成数量可用于 APS 进度更新。  
- 工单查询数据为 APS 提供执行状态反馈。  

## 5. 权限与审计

- 权限粒度：查看、创建、编辑、打印。  
- 开工检查记录、交班记录需记录审计日志。  

## 6. 与其他模块关系

- **生产工单模块**：工单查询数据来源于生产工单模块。  
- **生产派工模块**：派工工作查询关联派工任务。  
- **成品质量管理模块**：开工检查实绩与成品质量管理共享数据。  
- **班组管理模块**：交班记录关联班组信息。  
- **异常联络单管理模块**：检查不通过可触发异常联络单。  
- **APS 系统**：执行进度与状态反馈。
