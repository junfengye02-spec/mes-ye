# 基础数据模块需求分析

## 1. 模块概述

基础数据模块用于沉淀生产主数据，支撑工艺、计划、生产、质量等模块的统一引用，避免重复维护与口径不一致。本模块覆盖以下子功能：

- 物料档案
- 物料价格维护
- 工作中心主数据

## 2. 角色与权限

- 物料管理员：物料档案与价格维护的增删改导入
- 工艺工程师：工作中心信息维护与批量调整
- 计划/生产人员：只读查询
- 质量人员：只读查询（关注“需要检验”等标识）

权限粒度建议区分：查看、编辑、删除、批量编辑、数据导入。

## 3. 功能清单

- 物料档案：查询、新增、编辑、删除、批量编辑、数据导入、默认辅助计量单位维护
- 物料价格维护：查询、新增、编辑、删除
- 工作中心主数据：查询、新增、编辑、删除、批量编辑、数据导入

## 4. 页面需求

### 4.1 物料档案

**页面目标**  
统一管理物料主数据，支持多维属性与追溯方式配置，并提供批量编辑与导入能力。

**页面操作**  
- 批量编辑
- 新增
- 保存
- 数据导入
- 修改默认辅助计量单位
- 打开
- 删除
- 查询、清空、收藏/常用条件

**查询条件（示意）**  
- 物料编码（必填）
- 物料名称（必填）
- 物料类型（必填）
- 图号（必填）

**列表字段（示意）**  
- 物料编码（必填、唯一）
- 物料名称（必填）
- 物料类型（必填）
- 一级分类、二级分类
- G编码
- 产品类型、产品类别
- 机型、部件名称
- 工厂
- 基本计量单位（必填）
- ID
- 物料追溯方式（单件追溯/批次追溯/数量追溯）
- 序列号生成器、批号生成器
- 条码类型
- 需要检验
- 图号、材料牌号
- 产品外观图片
- 创建人、创建时间、修改人、修改时间

**业务规则**  
- 物料编码全局唯一，不可重复。
- “物料追溯方式”决定追溯粒度：  
  - 单件追溯：必须配置序列号生成器。  
  - 批次追溯：必须配置批号生成器。  
  - 数量追溯：序列号与批号可为空。  
- 需要检验为真时，后续报检/质检流程需能识别此物料。

**导入与批量编辑**  
- 支持模板导入，导入时进行字段完整性与编码唯一性校验。  
- 批量编辑支持选择字段批量更新，记录操作日志。

### 4.2 物料价格维护

**页面目标**  
维护物料单价与计量单位，用于成本核算与报价参考。

**页面操作**  
- 新增、编辑、删除
- 查询

**列表字段（示意）**  
- 物料单价
- 单位
- 物料
- 创建时间、创建人
- 修改时间、修改人

**业务规则**  
- 单价为非负数，支持小数。  
- 物料必须存在于物料档案。

### 4.3 工作中心主数据

**页面目标**  
统一维护工作中心信息，包含产能、批量、效率与排程约束。

**页面操作**  
- 批量编辑
- 新增
- 保存
- 数据导入
- 查询、清空、收藏/常用条件

**查询条件（示意）**  
- 工作中心编码（必填）
- 工作中心名称（必填）
- 工作中心分类（必填）
- 业务单元（必填）

**列表字段（示意）**  
- 工作中心编码（必填、唯一）
- 工作中心名称（必填）
- 工作日历
- 资源排序
- 使用量、使用量单位
- 处理批量
- 效率
- 资源种类
- 炉资源类型
- 资源能力
- 工序不中断（布尔）
- 工序不跨天（布尔）
- 固定节拍点生产（布尔）
- 创建时间、修改时间

**业务规则**  
- 编码全局唯一。  
- 数值字段（处理批量/效率/资源能力）需为正数或零。  
- 排程相关字段（工序不中断、工序不跨天、固定节拍点生产）影响计划与派工计算。

## 5. 数据权限与审计

- 所有新增/编辑/删除操作必须记录操作人、时间与变更内容。  
- 导入与批量编辑需记录批次号与结果（成功/失败条数）。

## 6. 与其他模块关系

- 工艺管理：工序模板与工序信息引用工作中心主数据。  
- 计划管理/生产工单：计划与派工依赖物料与工作中心信息。  
- 报检管理：依据物料“需要检验”标识触发检验流程。
