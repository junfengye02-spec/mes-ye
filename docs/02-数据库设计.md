# 数据库设计

## 1. 设计原则

- 统一主键：`BIGINT` 自增或雪花 ID。  
- 统一审计字段：`created_by`、`created_time`、`updated_by`、`updated_time`。  
- 逻辑删除：`deleted` 字段（0 未删除，1 已删除）。  
- 关键编码字段建立唯一索引。

## 4. APS 集成表

| 字段 | 类型 | 约束 | 说明 |

| config_value | VARCHAR(500) | NOT NULL | 配置值 |
| config_desc | VARCHAR(200) |  | 配置说明 |

| created_by | VARCHAR(50) |  | 创建人 |
| created_time | DATETIME |  | 创建时间 |
| updated_by | VARCHAR(50) |  | 修改人 |
| updated_time | DATETIME |  | 修改时间 |

### 4.2 APS 同步日志表 `mes_aps_sync_log`

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK | 主键 |
| batch_id | VARCHAR(64) | UNIQUE, NOT NULL | 同步批次号（UUID） |
| sync_direction | VARCHAR(20) | NOT NULL | 同步方向（DOWNSTREAM/UPSTREAM） |
| sync_type | VARCHAR(50) | NOT NULL | 同步类型（ORDER/WORKORDER/INVENTORY/ABNORMAL） |
| total_count | INT |  | 数据总量 |
| success_count | INT |  | 成功数量 |
| fail_count | INT |  | 失败数量 |
| status | VARCHAR(20) | NOT NULL | 同步状态（SUCCESS/FAIL/PARTIAL） |
| start_time | DATETIME |  | 开始时间 |
| end_time | DATETIME |  | 结束时间 |
| duration_ms | BIGINT |  | 耗时（毫秒） |
| error_message | TEXT |  | 错误信息 |
| created_time | DATETIME |  | 创建时间 |

> 建议在 `batch_id` 上建立唯一索引，在 `sync_direction` + `sync_type` + `created_time` 上建立联合索引。

### 4.3 APS 同步数据明细表 `mes_aps_sync_detail`

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK | 主键 |
| batch_id | VARCHAR(64) | NOT NULL | 同步批次号 |
| data_type | VARCHAR(50) | NOT NULL | 数据类型（ORDER/WORKORDER/INVENTORY） |
| data_id | BIGINT |  | 关联数据ID |
| data_no | VARCHAR(100) |  | 关联数据编号（如订单号） |
| sync_action | VARCHAR(20) | NOT NULL | 同步动作（CREATE/UPDATE/DELETE） |
| sync_status | VARCHAR(20) | NOT NULL | 同步状态（SUCCESS/FAIL/PENDING） |
| aps_data | JSON |  | APS 侧数据快照 |
| mes_data | JSON |  | MES 侧数据快照 |
| error_message | VARCHAR(500) |  | 错误信息 |
| retry_count | INT | DEFAULT 0 | 重试次数 |
| created_time | DATETIME |  | 创建时间 |
| updated_time | DATETIME |  | 修改时间 |

> 建议在 `batch_id` 上建立索引，在 `data_type` + `data_no` 上建立联合索引。

### 4.4 APS 数据映射表 `mes_aps_data_mapping`

| 字段 | 类型 | 约束 | 说明 |

| mes_name | VARCHAR(200) |  | MES 名称 |

| aps_name | VARCHAR(200) |  | APS 名称 |
| enabled | TINYINT(1) | DEFAULT 1 | 是否启用 |
| created_by | VARCHAR(50) |  | 创建人 |
| created_time | DATETIME |  | 创建时间 |
| updated_by | VARCHAR(50) |  | 修改人 |

### 4.5 APS 待同步队列表 `mes_aps_sync_queue`

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK | 主键 |
| sync_direction | VARCHAR(20) | NOT NULL | 同步方向（DOWNSTREAM/UPSTREAM） |
| sync_type | VARCHAR(50) | NOT NULL | 同步类型 |
| data_type | VARCHAR(50) | NOT NULL | 数据类型 |
| data_id | BIGINT |  | 关联数据ID |
| data_no | VARCHAR(100) |  | 关联数据编号 |
| priority | INT | DEFAULT 5 | 优先级（1最高，10最低） |
| sync_status | VARCHAR(20) | NOT NULL | 状态（PENDING/PROCESSING/SYNCED/FAILED） |
| retry_count | INT | DEFAULT 0 | 已重试次数 |
| max_retry | INT | DEFAULT 3 | 最大重试次数 |
| next_retry_time | DATETIME |  | 下次重试时间 |
| payload | JSON |  | 同步数据载荷 |
| error_message | VARCHAR(500) |  | 错误信息 |
| created_time | DATETIME |  | 创建时间 |
| updated_time | DATETIME |  | 修改时间 |

> 建议在 `sync_status` + `priority` + `created_time` 上建立联合索引，用于定时任务按优先级查询待同步数据。
