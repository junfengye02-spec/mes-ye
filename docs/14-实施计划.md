## 1. 项目概况

### 1.1 技术栈

| 层级 | 技术选型 | 版本 |
|------|---------|------|
| 后端语言 | Java | 17 |
| 后端框架 | Spring Boot | 3.x |
| ORM | MyBatis Plus | 3.5.x |
| 数据库 | MySQL | 8.0 |
| 缓存 | Redis | 7.x（可选） |
| 前端框架 | Vue 3 + TypeScript | 3.4.x |
| 前端 UI | Element Plus | 2.x |
| 状态管理 | Pinia | 2.x |
| HTTP 客户端 | Axios | 1.x |
| 构建工具 | Maven（后端）/ Vite（前端） | - |
| 数据库迁移 | Flyway | 9.x |

### 1.2 架构决策记录

| 决策项 | 选择 | 原因 |
|--------|------|------|
| 整体架构 | **单体多模块** | 与 APS 单体版一致，降低初期复杂度 |
| 认证授权 | **暂不实现** | 先专注业务模块，后续补充 |
| 国际化 | **仅中文** | 当前无多语言需求 |
| 数据权限 | **暂无隔离** | 后续按工厂/组织维度扩展 |
| 文件存储 | **本地文件系统** | 后续可切换至 MinIO/OSS |
| APS 集成 | **预留接口，Mock 联调** | APS 已部署但无 MES 接口 |

### 2.3 核心基类与约定

```java
// 统一返回体
R.ok()                  // 200 成功无数据
R.ok(data)              // 200 成功带数据
R.fail("错误信息")      // 500 失败
R.fail(ResultCode.XXX)  // 指定错误码

// 基础实体（所有 Entity 继承）
BaseEntity {
    Long id;
    String createdBy;
    LocalDateTime createdTime;
    String updatedBy;
    LocalDateTime updatedTime;
    Integer deleted;  // 逻辑删除
}

// 分页查询
PageQuery {
    Integer pageNum = 1;
    Integer pageSize = 20;
}

PageResult<T> {
    List<T> list;
    Long total;
}

// Service 接口命名规范
I{Entity}Service extends IService<Entity> {
    PageResult<XxxVO> page(XxxQuery query);
    XxxVO getDetail(Long id);
    Long create(XxxDTO dto);
    void update(Long id, XxxDTO dto);
    void delete(Long id);
}
```

## 7. 关键设计约定

### 7.1 数据库约定

- 主键：`BIGINT` 自增
- 审计字段：`created_by`, `created_time`, `updated_by`, `updated_time`
- 逻辑删除：`deleted` (0=正常, 1=已删除)
- 唯一索引排除已删除记录（应用层控制）
- 字符集：`utf8mb4`
- 引擎：`InnoDB`

### 7.2 接口约定

- RESTful 风格：GET 查询, POST 新增, PUT 修改, DELETE 删除
- 统一返回体：`R<T>` (`code`, `message`, `data`)
- 分页参数：`pageNum` + `pageSize`
- 排序参数：`orderBy` + `orderDir`

### 7.3 命名约定

| Service 实现 | 大驼峰 + `ServiceImpl` | `WorkOrderServiceImpl` |

## 8. 风险与缓解措施

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| APS 接口未全部就绪 | 集成模块无法完整联调 | Mock Server + 同步开关 + 降级策略 |
| 表结构后期变更 | 迁移成本 | Flyway 版本管理 + 向后兼容 |
| 模块间循环依赖 | 编译失败 | Maven 模块依赖单向，事件驱动解耦 |
| 并发数据一致性 | 库存/状态不一致 | 乐观锁 + 事务控制 |
| 大量数据导入 | 超时/OOM | 分批处理 + 异步任务 |
