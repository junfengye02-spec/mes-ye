# 物料管理模块需求分析

## 1. 模块概述

物料管理模块用于管理生产过程中的物料流转，包括库存查询、领料申请、退料管理、完工入库等功能，支撑生产执行的物料需求，并为 APS 系统提供库存约束与物料消耗反馈。

### 库存查询
- 存储地点库存

### 领料管理

- 生产领料（按物料）
- 生产领料单管理
- 维修品生产领用申请（待补充）

### 退料管理
- 生产工单退料

## 4. 业务规则

### 4.1 存储地点库存

- 库存类型分为：非限制库存、质检库存、冻结库存。  
- 非限制库存：可正常使用的库存。  
- 质检库存：待质检的库存，不可直接领用。  
- 冻结库存：被冻结的库存，不可使用。  
- 库存数据支持按存货组织、存储地点、物料、班组等维度查询。  

### 4.2 生产工单领料申请

- 领料申请必须关联工单。  
- 需求数量来源于工单的物料需求（BOM 展开）。  
- 待领料数量 = 需求数量 - 已领料数量。  
- 本次领料数量不得超过待领料数量。  
- 领料完成后更新库存（非限制库存减少）。  
- 最终标识：标记该物料是否已完成所有领料。  

### 4.3 生产领料（按物料）

- 以物料为主维度汇总领料需求，便于仓库按物料批量处理。  
- 总需求数量 = 该物料所有待领工单的需求数量之和。  
- 总待领料数量 = 总需求数量 - 已领料数量。  
- 可用库存来源于存储地点库存的非限制库存。  
- 支持展开查看该物料关联的所有工单明细。  
- 批量领料时自动按需求时间优先分配（先到先领）。  
- 本次领料数量不得超过待领料数量和可用库存的较小值。  
- 领料完成后同步更新库存和工单领料状态。  

### 4.4 生产领料单管理

- 领料单管理提供多维度视图：我发起的、部门发起的、按行/按单。  
- 支持查看未完成的领料行和领料单状态。  
- 可追溯发货仓库、发货存储地点、工位等信息。  

### 4.5 完工入库（新制品/维修品/不可维修品）

- 完工入库申请和入库单分两个环节：先申请、后入库。  
- 入库类型：新制品、维修品、不可维修品，页面结构相同。  
- 完工入库关联生产工单。  
- 收货数量与工单产出数量进行核对。  
- 差异数量 = 收货数量 - 计划数量，需填写差异原因。  
- 入库完成后更新库存（非限制库存增加）。  
- 状态流转：创建 → 审核 → 入库完成。  

### 4.6 生产工单退料

- 退料关联工单和领料申请。  
- 退料需选择原领料申请进行关联。  
- 退料完成后更新库存（非限制库存增加）。  
- 支持打印过程信息卡。  

### 4.7 发货签收

- 发货签收确认物料从仓库发出。  
- 待签收数量 = 计划发货数量 - 已签收数量。  
- 签收后更新领料状态。  
- 记录发货人、发货时间。  

### 4.8 与 APS 交互

- 库存数据为 APS 排程提供物料约束。  
- 领料消耗数据反馈给 APS，用于物料需求计划调整。  
- 完工入库数据反馈给 APS，更新产出进度。

#### 4.8.1 库存数据同步给 APS

APS 集成服务定时（每 5 分钟）将 MES 库存变动数据同步给 APS，用于排程时的物料约束。

**同步范围**：

| 库存类型 | 是否同步 | APS 用途 |
|----------|----------|----------|
| 非限制库存 | 是 | 作为 APS 可用库存约束 |
| 质检库存 | 否 | APS 不感知 |
| 冻结库存 | 否 | APS 不感知 |

**触发时机**：
- 领料确认后：非限制库存减少，写入待同步队列
- 完工入库后：非限制库存增加，写入待同步队列
- 退料确认后：非限制库存增加，写入待同步队列

**同步机制**：
1. 库存变动时，向 `mes_aps_sync_queue` 写入一条记录（`sync_type=INVENTORY`）
2. APS 集成服务定时批量查询待同步的库存数据
3. 按物料编码聚合最新库存，通过 `POST /api/mes/inventory/sync` 推送给 APS
4. 推送成功后标记队列状态为 SYNCED

**数据映射**：
- MES `material_code` → APS `Item.code`（通过数据映射表转换）
- MES `unrestricted_stock` → APS `Item.inventory`
- 如果物料编码映射不存在，记录错误日志（错误码 SYNC_004）

> 详细接口定义见 `13-APS集成模块/接口契约.md`，数据映射见 `13-APS集成模块/数据映射.md`。  

## 5. 权限与审计

- 权限粒度：查看、创建、编辑、审核、领料、入库。  
- 领料、入库等关键操作需记录审计日志。  

## 6. 与其他模块关系

- **基础数据模块**：物料档案是物料管理的数据基础。  
- **生产工单模块**：领料关联工单输入物料，入库关联工单输出物料。  
- **计划管理模块**：订单计划关联领料申请。  
- **成品质量管理模块**：质检库存与质量检验关联。  
- **APS 集成模块**：库存变动定时同步给 APS 作为排程物料约束；领料和入库触发同步队列。
