# 生产派工模块需求分析

## 1. 模块概述

生产派工模块用于将工单工作清单分配给人员、设备或班组，并支持人员逐级派工，实现从“工单”到“资源”的落地执行。

## 2. 功能清单

- 生产工作派工：人员分派、设备分派、工作组分派  
- 人员逐级派工  

## 3. 页面需求

### 3.1 生产工作派工 - 人员分派

**页面操作**  
- 查询、清空、收藏条件  
- 分派  

**过滤条件（示意）**  
- 分派状态（未分派/已分派）  
- 订单编号  
- 工序号  

**左侧人员列表**  
- 人员编号  
- 姓名  
- 已派工数  
- 资质  

**右侧任务列表（示意）**  
- 订单编号  
- 工序号  
- 分派人员  
- 工作名称  
- 计划工作中心  
- 序列号  
- 项目  

**交互规则**  
- 需先选中人员，再勾选任务进行分派。  

### 3.2 生产工作派工 - 设备分派

**左侧设备列表**  
- 设备编码  
- 设备名称  
- 已派工数  

**右侧任务列表（示意）**  
- 工作编号  
- 工作名称  
- 分派设备  
- 计划数量  
- 数量单位  
- 计划开始时间  

### 3.3 生产工作派工 - 工作组分派

**左侧班组列表**  
- 班组编码  
- 班组名称  

**右侧任务列表（示意）**  
- 工作编号  
- 工作名称  
- 分派工作组  
- 计划生产班组  

### 3.4 人员逐级派工

**页面特性**  
用于在班组内对已分派的任务进行人员级别细分。

**过滤条件（示意）**  
- 班组选择  
- 分派状态  
- 完成分派（勾选）  
- 订单编号  
- 工序号  

**左侧人员列表**  
- 人员编号  
- 姓名  
- 已派工数  
- 资质  

**右侧任务列表（示意）**  
- 订单编号  
- 工序号  
- 分派人员  
- 工作名称  
- 计划工作中心  
- 序列号  
- 项目  

## 4. 业务规则

- 任务仅允许在“未分派”状态被派工。  
- 同一任务可派给人员、设备或班组，但派工类型需区分。  
- 人员派工需校验人员资质是否满足工序要求。  
- 设备派工需校验设备归属与工序工作中心匹配。  
- 工作组派工后，才允许进入人员逐级派工。  
- 分派操作需记录派工人、派工时间与变更内容。  

## 5. 权限与审计

- 权限粒度：查看、分派、撤销分派、查询。  
- 派工与撤销需记录日志。  

## 6. 与其他模块关系

- 生产工单：派工任务来自工单工作清单。  
- 班组管理/人员管理/设备管理：派工资源来源。  
- 计划管理：派工完成度回写计划进度。  

## 7. 数据库设计（表结构）

以下为生产派工模块表结构设计（仅表结构，不生成 SQL 脚本）。

### 7.1 派工任务表 `mes_dispatch_task`

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| work_order_id | BIGINT | 工单ID |
| work_order_task_id | BIGINT | 工作清单ID |
| order_no | VARCHAR(100) | 订单编号 |
| process_no | VARCHAR(50) | 工序号 |
| work_name | VARCHAR(200) | 工作名称 |
| plan_work_center_id | BIGINT | 计划工作中心 |
| serial_no | VARCHAR(100) | 序列号 |
| project_name | VARCHAR(200) | 项目 |
| plan_qty | DECIMAL(18,4) | 计划数量 |
| qty_unit | VARCHAR(20) | 数量单位 |
| dispatch_status | VARCHAR(20) | 分派状态 |
| created_time | DATETIME | 创建时间 |
| updated_time | DATETIME | 修改时间 |
