# 工艺管理模块需求分析

## 1. 模块概述

工艺管理用于沉淀指示书、工序模板与工序信息等关键工艺数据，支撑生产工单生成与现场执行，并形成可追溯的工艺版本记录。

## 2. 功能清单

- 指示书产品信息
- 工序模板
- 指导书
- 工序信息批量编辑
- 喷涂条件表
- 机械加工程序表
- **制造BOM**

## 3. 业务流程（指示书产品信息）

1. 新建指示书（录入项目/WBS/产品信息）  
2. 填写收货前/收货检查/维修等阶段内容  
3. 保存与升级版本（查看历史版本）  
4. 查看流程日志  
5. 输出/查看指示书

- 替代料组

- 备注  

**替代料管理**  
- 主物料编码  
- 替代物料编码  
- 替代物料名称  
- 替代优先级  
- 替代比例  
- 生效日期  
- 失效日期  

**业务规则**  
- BOM编码 + 版本 唯一。  
- BOM 支持多层级嵌套（树形结构），最大层级建议不超过 10 层。  
- 同一产品可有多个 BOM 版本，同一时间只有一个版本生效。  
- BOM 状态流转：草稿 → 已发布 → 已停用。  
- 已发布的 BOM 不可直接编辑，需通过"版本升级"生成新版本。  
- 关联工序：定义物料在哪个工序投入，用于工单展开时按工序分配物料需求。  
- 替代料：当主物料库存不足时，可使用替代物料，替代优先级决定选用顺序。  
- 用量计算：实际需求 = 计划数量 × 单位用量 × (1 + 损耗率)。  
- 与 APS 交互：  
  - APS 获取 BOM 结构计算物料需求（MRP）。  
  - 物料约束（库存不足）反馈 APS 进行重排。  

#### 与 APS 的 BOM/工艺路线映射关系

> **核心原则**：MES 和 APS 各自维护 BOM/工艺路线数据，通过映射表关联。APS 是排程参数的主数据源，MES 是物料组成的主数据源。

**双方数据分工**：

| 数据项 | APS（ProductRouting） | MES（制造BOM） | 关联方式 |
|--------|---------------------|---------------|---------|
| 工序结构 | `processSequence` + `ProcessDefinition` | `mes_manufacturing_bom_item.process_no` | 通过工序映射表 |
| 排程工时 | `standardTime`、`setupTime`、`preSetupTime` | `mes_process_template.handle_time`（参考值） | APS 为准 |
| 物料投入 | `RoutingInput`（投入物料列表） | BOM明细（`supply_type`、`quantity`） | 通过物料映射表 |
| 物料产出 | `RoutingOutput`（产出物料列表） | BOM父件产品 | 通过物料映射表 |
| 默认资源 | `defaultResource` | `mes_process_template.work_center_id` | 通过工作中心映射表 |
| 外协标识 | `isOutsource` + `supplier` | `supply_type='委外'` | 通过供应商映射表 |
| 工序连接 | `connectionType`(SS/FS)、`lagTime` | - | APS 排程专用参数 |
| 换型时间 | `setupTime`、SetupMatrix | - | APS 排程专用参数 |
| 损耗率 | - | `mes_manufacturing_bom_item.loss_rate` | MES 独有 |
| 替代料 | - | `mes_bom_substitute` | MES 独有 |

**BOM 变更对 APS 的影响**：
- BOM 发布新版本后，如涉及工序增减或物料变更，相关订单可能需要重排
- 通过异常联络单（事件分类=工艺路线变更）触发 APS 重排评估
- BOM 中外协工序的变更需同步确认 APS 端 ProductRouting 的 `isOutsource` 标识

> 详细映射关系见 `13-APS集成模块/数据映射.md` 第 8 节。  

**与其他模块关系**  
- **基础数据**：物料编码来源于物料档案（APS 为物料主数据源，通过映射表关联）。  
- **生产工单**：工单创建时引用 BOM，展开输入物料清单。  
- **物料管理**：领料需求来源于 BOM 展开，入库产出对应 BOM 父件。  
- **工序模板**：BOM 物料与工序关联，定义物料投入时点。  
- **APS 集成模块**：BOM/工艺路线通过映射表与 APS ProductRouting 关联；BOM 是物料约束排程的核心数据。  

## 5. 数据权限与审计

- 指示书、工序模板、指导书均需审计追踪。  
- 版本升级记录操作人、时间与变更摘要。  
- 删除操作建议逻辑删除。  

## 6. 与其他模块关系

- 基础数据：工序模板、工序信息引用工作中心与物料信息。  
- 生产工单：指示书与工序模板驱动工单生成与派工。  
- 报检管理：工序类型为“检验工序”时触发检验环节。
