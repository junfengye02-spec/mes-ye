# 生产工单模块需求分析

## 1. 模块概述

生产工单模块用于将计划转化为可执行的生产任务，承载工单基础信息、工序清单、物料输入输出、检验清单、约束关系与文档附件，是生产执行与派工的核心载体。

## 2. 功能清单

- 生产工单列表：查询、新增、保存、打印过程信息卡、打开、强制完工  
- 生产工单详情：查看/编辑基本信息、工作清单、物料、检验与附件

## 4. 业务规则

- 工单号全局唯一，自动生成或手工录入均需校验重复。  
- 计划数量必须大于 0；数量单位必填。  
- 工单状态建议流转：创建 → 下发 → 执行中 → 完工；“强制完工”需特殊权限并记录原因。  
- 工单下发后不允许删除，可撤回或作废（需权限）。  
- 打印过程信息卡基于工单与工作清单生成。  
- 文档附件支持多文件，需记录版本与修改时间。

### 4.1 与 APS 交互（工单状态反馈）

工单状态变更时，通过 APS 集成服务反馈给 APS 系统，确保排程数据与实际执行同步。

**状态变更触发 APS 操作**：

| 工单状态变更 | APS 操作 | 触发方式 | 说明 |
|-------------|----------|----------|------|
| 创建 → 下发 | 无 | - | MES 内部流转，不通知 APS |
| 下发 → 执行中（开工） | 锁定 APS 订单 | 写入同步队列 | 防止 APS 重排时调整已开工工单 |
| 执行中 → 完工 | 解锁 APS 订单 + 反馈完工数据 | 写入同步队列 | 释放 APS 资源占用 |
| 执行中 → 强制完工 | 解锁 APS 订单 + 反馈完工数据 | 写入同步队列 | 同上，附加强制完工原因 |

**工作清单与 APS 排程任务关联**：
- APS 的 `ScheduleTask` 可同步到 MES 工作清单 `mes_work_order_task`
- 通过订单号 + 工序顺序号进行关联
- APS 任务的资源分配（`resourceId`）映射到工作清单的计划工作中心

> 详细接口定义见 `13-APS集成模块/接口契约.md`，数据映射见 `13-APS集成模块/数据映射.md`。

## 5. 权限与审计

- 权限粒度：查看、创建、编辑、下发、强制完工、打印、附件维护。  
- 关键操作（下发、强制完工、删除）记录日志与操作人。  

## 6. 与其他模块关系

- **计划管理**：工单可由计划生成，回写完工与进度。  
- **工艺管理**：工作清单与工序信息来源于工艺模板。  
- **生产派工**：工单工作清单为派工任务来源。  
- **物料管理**：输入/输出物料与库存出入库联动。  
- **报检管理**：检验项目清单触发检验流程。  
- **APS 集成模块**：工单状态变更触发 APS 同步（锁定/解锁/完工反馈），工作清单可接收 APS 排程任务。
