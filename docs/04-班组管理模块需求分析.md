# 班组管理模块需求分析

## 1. 模块概述

班组管理用于维护生产班组基础信息，为派工、工序执行与产能统计提供组织维度支撑。

## 2. 功能清单

- 生产班组：查询、新增、编辑、启用/停用、数据导入

## 3. 页面需求

### 3.1 生产班组

**页面操作**  
- 新增  
- 数据导入  
- 查询  

**列表字段（示意）**  
- 班组编码  
- 班组名称  
- 生产组织  
- 启用（复选框）  
- 说明  
- 创建时间、创建人  
- 修改时间、修改人  

**业务规则**  
- 班组编码全局唯一。  
- 启用状态为“否”时，在派工与工序执行中不可选。  
- 生产组织建议来源于组织基础数据（如事业部/制造科）。  

**导入与校验**  
- 支持模板导入，校验编码唯一性与必填字段完整性。  
- 导入失败需提供错误行与原因提示。  

## 4. 数据权限与审计

- 支持查看/编辑/导入权限控制。  
- 新增、编辑、启用/停用操作记录审计。  

## 5. 与其他模块关系

- 生产派工：班组是派工与人员分配的基础维度。  
- 工艺管理：工序信息与工段/班组绑定。
